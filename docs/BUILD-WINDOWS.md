# Building the Windows x64 installer

## Local build (Windows)

Prerequisites:

- Node.js 20+ (this repo is developed on Node 22)
- Rust stable with the **MSVC** toolchain (`rustup default stable-x86_64-pc-windows-msvc`)
- Visual Studio Build Tools with "Desktop development with C++"
- WebView2 runtime (preinstalled on Windows 11)

```powershell
npm ci
npm run typecheck
npm run tauri build -- --bundles nsis
```

Outputs:

| Artefact | Path |
| --- | --- |
| NSIS installer | `apps/desktop/src-tauri/target/release/bundle/nsis/ARIA Image Studio_1.0.0_x64-setup.exe` |
| App executable (portable base) | `apps/desktop/src-tauri/target/release/aria-image-studio.exe` |
| Frontend bundle | `apps/desktop/dist/` |

The NSIS installer uses `installMode: currentUser`, so no elevation is requested. The portable build is the raw
`aria-image-studio.exe` copied next to the WebView2 loader — ship it as `ARIA-Image-Studio-1.0.0-portable.exe`.

## CI build (GitHub Actions)

`.github/workflows/build-windows.yml` runs on `windows-latest`, `workflow_dispatch`, or a `v*` tag:

1. `npm ci` with the committed lockfile
2. `npm run typecheck` and `npm run build`
3. Rust toolchain + cache (`Swatinem/rust-cache`)
4. `npm run tauri build -- --bundles nsis`
5. Uploads the installer, the raw exe and a checksum file as workflow artifacts
6. On a tag, creates/updates a GitHub Release with those files

No secrets are needed for the build. Code signing is intentionally absent in v1.0.0 — Windows SmartScreen will warn on
first run of an unsigned installer; that is expected and documented rather than hidden.

## Verification checklist

- Installer runs to completion, app launches, title bar reads "ARIA Image Studio".
- Welcome page reports the detected Codex version.
- Authentication imports an `auth.json`, status becomes `credentials_present`.
- AI Engine smoke test returns text.
- A real generation imports exactly the files created in `$CODEX_HOME/generated_images`.
- Diagnostics exports a report under `Exports/`.

## Reproducibility notes

- `apps/desktop/package-lock.json` is committed; use `npm ci`.
- Rust dependencies are locked by `Cargo.lock` when present; commit it after the first successful CI build.
- Icons are generated by `node scripts/generate-icons.mjs` (no binary assets in git history beyond the PNG/ICO files).
